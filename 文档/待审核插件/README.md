# 待审核插件（文档归档）

本目录是待审核插件的**文档/资料归档**，与 `plugins/待审核/` 对应。这里的插件**未接入面板、未审核**，仅供评审参考。

## 上架前必须先修

已知存在**命令注入**等安全问题的插件（至少包括，评审时需逐一复现并修复）：

- `webhook`
- `system_safe`
- `backup_ftp`

上述问题未修复前，**不得**将对应插件纳入面板内置插件列表，也不得对外发布。

## 审核清单（最低要求）

1. 修复命令注入 / 参数拼接问题（所有外部输入不得直接进入 shell）。
2. 补齐安装脚本的输入校验（插件名、版本号白名单）。
3. 按面板规范提供 `info.json` / 语言包，并通过静态门禁。
4. 审核通过后，才可从待审核目录移入正式插件目录，并同步更新本文档。
