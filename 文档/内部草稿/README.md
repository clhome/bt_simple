# 内部草稿

> **内部草稿，非正式文档，不对外承诺。**

本目录存放开发过程中的内部 TODO / 试验记录，**不属于面向用户或开发者的正式文档**，
不构成任何功能承诺、交付时间或对外口径。正式文档在 `文档/` 根目录、
`文档/御风面板说明书/`、`文档/插件统一开发规范.md` 等处。

## 为什么单独放这里

测评报告指出：这类内部草稿原先直接放在 `文档/` 根目录，会与正式文档混在一起，
让人误以为是对外承诺。集中到本目录后，`文档/` 根目录只保留正式文档。

## 现有草稿

| 文件 | 说明 |
| --- | --- |
| `待完成.md` | 迁移自文档根目录的开发待办（含 redis 报错粘贴），保持原样以不丢信息。 |

## 约定

- 本目录下的文件可以随时增删，不必保持正式文档的格式规范；
- 不要在这里写「对外承诺」性质的说明（那属于正式文档）；
- 引用仓库文件请写真实存在的路径 —— `testsuite/test_docs_hygiene.py`
  会校验 `文档/` 下不存在 0 字节文件、且文档里的本地路径引用不指向不存在的文件。
