# 御风面板（bt_simple）运行依赖
#
# 锁定策略（对应《参考/优化260910.md》R2）：
#   1. 只对“已在代码中实际 import”的包收紧上界（防止升级到不兼容大版本），
#      不对需要按 Python 版本现场编译的包（gevent/psutil/cryptography 等）做死版本锁定。
#   2. Flask 生态必须协同：flask / Werkzeug / Jinja2 / SQLAlchemy 均加上界；
#      其中 Python>=3.9 走 Flask 3.x（安全修复版），<3.9 保持 Flask 2.x，见下方分档说明。
#   3. 移除代码中从未使用的 flask-session（会话由 Flask 原生签名 Cookie 实现，
#      见 web/admin/__init__.py 的 SESSION_* 配置，导入的是 flask.session）。
#   4. WebSocket：保持 gunicorn gthread + async_mode=threading，通过
#      simple-websocket 让 threading 驱动支持真正的 WebSocket（webssh），
#      避免切 gevent 后长任务 execShell 阻塞事件循环导致面板整体卡死。

#   flask/Werkzeug 的修复版本（flask>=3.1.3 / Werkzeug>=3.1.6）均要求 Python>=3.9，
