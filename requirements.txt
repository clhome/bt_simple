# --- 无界依赖例外清单（P2-9）---
# ---------------------------------------------------------------------------------
# 下面这些包**故意**没有版本边界。纪律：仓库离线开发，无法核对上游最新版，
# 凭印象写一个数字比不写更糟（写小了挡安装、写大了等于没锁）。所以这里不写数字，
# 而是把「为什么可以不写」和「什么时候必须回来复核」显式记下来，由门禁强制台账完整：
#   * 新增一条无版本边界的依赖却没登记在本节 → testsuite/test_requirements_bounds.py 变红；
#   * 本节登记项在 requirements.txt 里不存在、或已经补上了边界 → 同样变红（防台账腐烂）。
# 登记格式（每行一条，包名与上面 requirements.txt 里的写法逐字一致）：
#   <包名>  —— 理由：…；复核时机：…
# 本清单共 11 条。共同的复核时机：**下次联网跑 pip-compile 生成 requirements.lock 时**
# （scripts/gen_requirements_lock.sh，或 CI 的 security-scan.yml `lock` job），
# 届时锁文件里有确切版本，可按需把某条升级为「A 类补下界」并从本节删除。
#
#   Flask-Compress  —— 理由：纯 Python 的 Flask 压缩中间件，web/admin/__init__.py 直接 import Compress，并按 web/core/resources.py 推导的算法列表设 COMPRESS_ALGORITHM；对外 API 面极小（Compress(app) + 配置项），无 C 扩展；它是最初 14 项清单之外、由守卫用例扫出的第 15 个无界依赖（P2-9 整改时补登记）；开发机未安装，无实测版本依据；复核时机：下次联网生成锁文件时定界。
#   pyotp  —— 理由：纯 Python 实现、无 C 扩展 / ABI 约束；面板只在两步验证（TOTP）路径按需 import（web/admin/dashboard/login.py、web/admin/setting/secondary_verifiy.py），只用 TOTP / random_base32 极小 API 面；开发机未安装，无实测版本依据；复核时机：下次联网生成锁文件时定界。
#   pymongo  —— 理由：纯 Python（可装 C 扩展但非必需）的 MongoDB 驱动，面板主进程不依赖，仅 data_query / mongodb 插件的连接与探测路径 import（plugins/data_query/nosql_mongodb.py、plugins/mongodb/index.py）；驱动与服务端版本兼容面宽，代理由插件路径自行容错（import 失败只降级为「未安装驱动」提示）；开发机未安装，无实测版本依据；复核时机：下次联网生成锁文件时定界。
#   pymemcache  —— 理由：纯 Python 的 memcached 客户端，只被 plugins/data_query/nosql_memcached.py 使用（import 失败即降级为「未装驱动」提示）；无 C 扩展、上游无已知破坏性大版本；开发机未安装，无实测版本依据；复核时机：下次联网生成锁文件时定界。
#   redis  —— 理由：纯 Python 的 redis 客户端，只被 plugins/data_query/nosql_redis.py 与 plugins/data_query/common_db.py 的连通性探测使用；面板核心不 import，插件侧 import 失败已容错；开发机未安装，无实测版本依据；复核时机：下次联网生成锁文件时定界。
#   croniter  —— 理由：纯 Python 的 cron 表达式解析库；本机实测 web/ plugins/ scripts/ 内**零 import**（历史快照里 web/admin/setup/init_cron.py 曾用过，现已改用自身 utils.crontab）；保留是依赖清单既成事实，删依赖不在 P2-9 范围；复核时机：下次依赖清理轮次确认仍无引用后按死依赖删除，或联网生成锁文件时定界。
#   tldextract  —— 理由：纯 Python 的域名后缀解析；只被 web/utils/site.py 一处使用，且外层 try/except 包裹（解析失败降级）；默认行为可能按需下载公共后缀列表，故**不宜**用上界锁死其升级；开发机未安装，无实测版本依据；复核时机：下次联网生成锁文件时定界。
#   pyTelegramBotAPI  —— 理由：通知渠道（Telegram）用的 SDK，只在 web/core/yf/panel.py、web/core/yf/__init__.py 按需 import；它与 telebot 在 PyPI 上提供同名模块（面板代码只 import telebot），两者的边界必须一起对齐才有意义，单给一条加上界会造成解析冲突；开发机未安装，无实测版本依据；复核时机：下次联网生成锁文件时给两条定同一口径的界。

#   zstd  —— 理由：可选 HTTP 压缩编码器（同 brotli 口径），面板代码零 import，只在 web/core/resources.py 的算法候选列表里以字符串 'zstd' 出现；开发机未安装，无实测版本依据；复核时机：下次联网生成锁文件时定界。
