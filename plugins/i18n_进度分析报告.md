## 二、架构现状（改造前必须理解）

### 1. 语言包结构
```
plugins/<插件名>/lang/{zh-CN,zh-TW,en,de,fr,it}.json
```
扁平字典，**键 = 中文原文，值 = 译文**：
```json
{ "正在获取...": "Loading...", "保存": "Save" }
```
- zh-CN.json 是**原文基线**（键值相同），是唯一的事实来源。
- 所有语言文件的键**必须与 zh-CN 一致**，多一个少一个都会导致回退到中文。

### 2. 后端注入（零延迟）
`web/admin/plugins/__init__.py` 的 `setting()` 路由：
```python
lang = get_current_lang()                       # core/i18n.py
lang_dict = json.loads(readFile(plugin_dir + '/lang/' + lang + '.json'))
# 拼到 index.html 尾部，服务端直出，免二次请求
window._pluginDicts['<name>'] = {...};
localStorage.setItem('yf_plang_<name>_<lang>', ...)
```

### 3. 前端翻译入口
`web/static/app/i18n.js`：
- 插件 JS 顶部固定写法：`var pt = YfI18n.createPluginTranslator('<插件名>');`
- `pt(key)` —— **只接受 1 个参数**，支持 `{1}{2}` 位置插值，**不支持 HTML**。
- `msgTpl(msg, args)`（`web/static/app/public.js:540`）配合 `pt()` 做插值。
- `translatePluginDOM()` 用 MutationObserver **自动翻译弹窗 DOM**（菜单、表头、按钮、placeholder、title、版权署名），所以**静态 HTML 里的中文多数能自动翻译**，但：
  - 只在 `.bt-w-menu p / th / button / .btn / select option / placeholder / title` 等**白名单选择器**内生效；
  - `layer.msg()` / `layer.confirm()` / `layer.prompt()` / 动态拼接的 HTML 片段**不在自动翻译范围**，必须手动 `pt()`。

## 四、必须遵守的功能性红线（否则会出错）

### 🔴 红线 1：语言包 value 严禁含 HTML
两处代码会**强制剥离或直接抛异常**：
- `web/core/i18n.py:344` `assert_no_html_in_translations()` → **`raise ValueError`**
- `web/static/app/i18n.js:758` `tSafe()` → `stripHtml()` + console 告警

**错误写法** ❌
```json
{ "<li>通过DNS验证获取SSL证书!</li>": "<li>Obtain SSL via DNS validation!</li>" }
```
**正确写法** ✅ —— 标签留在代码里，只把纯文本入包：
```js
// acme_pandominassl_apply/js/common.js
'<li>' + pt('通过DNS验证获取SSL证书!') + '</li>'
```

### 🔴 红线 2：拼接串必须改成整句模板
**错误** ❌ —— 拼接后无法命中语言包，且语序在德/法/意中必然错乱：
```js
layer.confirm('您真的要' + d + name + ver + '服务吗？')
```
**正确** ✅
```js
layer.confirm(msgTpl(pt('您真的要{1}{2}{3}服务吗？'), [d, name, ver]))
// lang: "您真的要{1}{2}{3}服务吗？": "Are you sure you want to {3} the {2} {1} service?"
```
德/法/意允许调整 `{n}` 顺序，这正是位置占位符存在的意义。

### 🔴 红线 3：`pt()` 结果不可再嵌 HTML
`pt()` 返回的是纯文本。构建富文本请用 `tSafe.html(key, {html_x: ...})`；`pt()` 后拼接 HTML 标签是安全的（红线 1 的正确写法），但**不要把 HTML 放进翻译值**。

### 🔴 红线 4：CSV 导出等含格式控制符的串不要翻译控制符
```js
'\uFEFF时间,IP,规则名,原因\n'   // fail2ban.js:786
'\uFEFF时间,域名,IP,URI,规则名,原因\n'  // op_waf.js:2168
```
翻译时**必须保留 `\uFEFF`（BOM）和 `\n`**，否则导出的 CSV 在 Excel 中中文乱码、列错位。建议拆成 `'\uFEFF' + pt('时间,IP,规则名,原因') + '\n'`。

### 🔴 红线 5：参数名 / 字段名 / 路径不得翻译
如 `OLLAMA_MODELS`、`max_children`、`/var/lib/docker/volumes`、`restore`、`reset master`、`0.0.0.0` 等，出现在提示语中时**保持原样**，仅翻译周边说明文字。
