# 待审核插件（未接入面板）

本目录下的插件**未接入面板、未审核**，默认不会被面板加载或安装，仅供归档与后续评审。

## 上架前必须先修

已知存在**命令注入**等安全问题的插件（至少包括，评审时需逐一复现并修复）：

- `webhook`
- `system_safe`
- `backup_ftp`

上述问题未修复前，**不得**将本目录插件纳入面板内置插件列表，也不得对外发布。

## 审核清单（最低要求）

1. 修复命令注入 / 参数拼接问题（所有外部输入不得直接进入 shell）。
2. 补齐安装脚本的输入校验（插件名、版本号白名单）。
3. 按面板规范提供 `info.json` / 语言包，并通过静态门禁。
4. 审核通过后，才可从本目录移入 `plugins/` 正式插件目录。
