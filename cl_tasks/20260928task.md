# 第二轮：修复第一轮引入的回归，并把同类问题一次扫干净

> 用户反馈：改完后封锁历史的「时间」筛选出现折叠 —— `Custom time` 输入框盖住了 `Today/7 Days`，
> 只剩 `ays` / `30 Days` 可见（截图 2）。要求修复**这类问题涉及的所有页面**。

## 六、回归根因（我第一轮的错）

第一轮把时间按钮组从 `display: inline-table` 改成了 `display: inline-flex`。但 bootstrap 的
`.input-group` 是 **table 布局**：`.input-group .form-control` 带 `float:left; width:100%; z-index:2`，
`.input-group-btn` 依赖相邻 `table-cell` 定位。切成 flex 后：

- `.last-span`（包住 input 的 span）成了 flex item，`width:100%` 解析异常且 `z-index:2` 抬升 → **输入框直接盖在按钮上**；
- 表现即截图 2：`Custom time` 输入框压住 `Today / Yesterday / 7 Days`。

**结论**：`inline-table` 里的 `width:350px` 是 bootstrap 表格的“最小宽度”，内容放不下时表格自己会撑开，
它**本来就不是**按钮重叠的原因；真正的原因是外层 `justify-content:space-between` **不允许换行**，
让右侧按钮组被压缩断词。所以正确修法是：**只给外层加 `flex-wrap`，内层保持 table 语义**。

## 九、经验（写进本仓库的教训）

> **bootstrap 组件不要随便改 `display`**：`.input-group` 依赖 table-cell 布局，
> `inline-table → inline-flex` 会让 `.form-control` 的 `float/width:100%/z-index` 反过来盖住按钮。
> 想解决“挤压”，改**外层容器的换行能力**，不要改组件内部的显示类型。
